# SHASHANK — THE WOLF

A cinematic, streaming-inspired portfolio for **Shashank Singh Bisht**: Software Engineer (AEM · Java · .NET) at HCLTech.
Every section is an episode, every project is an Original.

> A personal portfolio with a fictional streaming-platform look. It is not affiliated with any streaming service and uses none of their logos.

## Run it locally

Requires **Node.js 18+**.

```bash
npm install
npm run dev
```

Production build: `npm run build` → static site in `dist/` (deploy to Netlify, Vercel or GitHub Pages).

## Updating content

All content lives in **`src/data/portfolio.ts`**. Resume PDF: `public/assets/Shashank_Singh_Bisht_Resume.pdf`.

**Stack:** React 18, TypeScript, Vite 6, Tailwind CSS 4, Framer Motion 11, Lenis.

🔗 **Live site:** https://shashank-ssb.netlify.app

Design inspired by [Sushmita Dasari's Portfolio_series](https://github.com/Sushmitadasari/Portfolio_series). Content and branding are my own.
